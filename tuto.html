1. Instalación

Primero se instala la herramienta OSINT que se utilizará para realizar la investigación. 

sudo apt install sherlock

2. Uso de la herramienta

Una vez instalada, se puede utilizar un nombre de usuario para realizar una búsqueda en diferentes plataformas. 

sherlock SADYSA

3. Búsqueda con personas de confianza

También se puede recopilar información mediante personas de confianza que conozcan al objetivo. La información debe proporcionarse voluntariamente y respetando la privacidad.

4. Recopilación de información

Se reúnen los datos obtenidos mediante las diferentes fuentes y se comparan para determinar cuáles son relevantes para la investigación.
